# UI 设计规范

目标：界面清楚、克制、好扫读。学生端让人专注在“代码 ↔ 波形 ↔ 硬件”的对应上；教师端信息多但层级分明。做页面时对照 docs/ui-prototype.html。

## 1. 设计原则
1. **一屏一个主任务，一个主按钮。** 做题工作台的主按钮随步骤变化（提交预测 → 仿真 → 检查 → ……），其他操作用次要按钮
2. **三处联动，同一信号同一高亮。** 代码行、波形行、硬件面板里的同一个信号，悬停或选中时用同一种高亮色
3. **对错不只靠颜色。** 一律“颜色 + 图标 + 文字”：对 ✓、对不上 ✗、未判定 ?
4. **学生端降低焦虑。** 不显示排名；不用大面积红色；文案说“对不上”“再看看”，不说“错误”“失败”
5. **教师端从概括到明细。** KPI 卡 → 图表 → 表格 / 详情，从上到下逐层展开
6. **动效克制。** 过渡不超过 200ms，只用于状态变化（展开、切换、结果出现）

## 3. 设计变量（写进 Ant Design 主题 token 和 CSS 变量，全站统一引用，不在组件里写死颜色）

### 3.1 颜色
| 用途 | 变量名 | 色值 |
|---|---|---|
| 主色 | `--c-primary` | #3B5BDB |
| 主色浅底 | `--c-primary-bg` | #EEF2FF |
| 页面背景 | `--c-bg` | #F6F7F9 |
| 卡片 / 面板 | `--c-surface` | #FFFFFF |
| 分隔线 / 边框 | `--c-border` | #E5E7EB |
| 正文 | `--c-text` | #1F2937 |
| 次要文字 | `--c-text-2` | #6B7280 |
| 成功 / 对 | `--c-success` | #16A34A |
| 警示 | `--c-warning` | #D97706 |
| 对不上 / 出错 | `--c-error` | #DC2626 |
| 对不上浅底 | `--c-error-bg` | #FEE2E2 |
| 联动高亮 | `--c-link` | #FDE68A（代码行、波形行同时使用） |

### 3.2 四象限与掌握等级（学生端、教师端通用）
| 内部代码 | 学生端名称 | 颜色 | 图标 |
|---|---|---|---|
| mastered | 真掌握 | #2563EB | 实心圆 ● |
| fragile | 会写但没把握 | #D97706 | 半实心圆 ◐ |
| design_gap | 设计偏差 | #7C3AED | 菱形 ◆ |
| concept_gap | 概念未通 | #6B7280 | 空心圆 ○ |
| not_started（仅掌握等级） | 未开始 | #E5E7EB 底 + #9CA3AF 字 | 短横 – |
| learning（仅掌握等级） | 学习中 | #BFDBFE | 圆环 ◌ |

说明：知识点掌握等级只有四级（未开始、学习中、会写但没把握、真掌握）；单次尝试的结果用四象限。两者共用颜色，规则见 docs/learner-model.md。

### 3.3 字体与字号
- 中文界面：`"PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 代码、波形、数值：`"JetBrains Mono", "Fira Code", Consolas, monospace`
- 字号：12（辅助说明）、14（正文、表格）、16（卡片标题）、20（页面标题）、28（KPI 数字）
- 行高：正文 1.6，表格 1.5，代码 1.5

### 3.4 间距、圆角、阴影
- 4px 网格：4 / 8 / 12 / 16 / 24 / 32
- 卡片内边距 16（紧凑）或 24（宽松）；卡片间距 16
- 圆角：卡片 8，按钮和输入框 6，标签 4
- 阴影只用一层：`0 1px 2px rgba(16, 24, 40, .06)`；弹层用 `0 8px 24px rgba(16, 24, 40, .12)`

## 4. 布局
- 学生端：顶部导航（学习首页 / 题目 / 复习 / 我的学情）；做题工作台全屏三栏（尺寸见 docs/pages.md S4）
- 教师端：左侧菜单宽 220px，内容区 12 栏网格，最大宽度 1440px，KPI 卡一行 5 张
- 响应式：“我的学情”“复习”在 ≤ 768px 时改为单列；做题工作台和教师端只保证 ≥ 1280px

## 6. 波形组件（WaveformView）规格
- 结构：左侧信号名列 140px（等宽字体，右对齐）；右侧时间轴，每个 STEP 一列，列宽 44px；每个信号一行，行高 32px；顶部一行 STEP 序号，时钟信号画上升沿箭头
- 单比特：高电平、低电平用 1.5px 折线，颜色 `--c-text`
- 总线：六边形值框，底色 `--c-primary-bg`，边框 #6366F1，框内显示值（默认十六进制，可切换二进制）
- X：红色斜线填充；Z：灰色虚线居中
- 预测格（predict 模式）：虚线框 + 居中“?”，填写后显示学生的值；当前焦点格主色实线框
- 对照（compare 模式）：每个输出信号两行，“期望”在上、“你的电路”在下，行名左侧用小字标注
  - 你的电路与期望不同的格子：底色 `--c-error-bg`、边框 `--c-error`
  - 预测徽标：画在“你的电路”行预测格的右上角，直径 14px；预测对为 `--c-success` 底白色 ✓，预测错为 `--c-warning` 底白色 ✗，并在格子下方用琥珀色小字写“你预测 1”
- 第一个对不上的周期：红色 2px 竖线贯穿所有信号行，底部左侧红底白字标签“第一个对不上的周期”
- 联动高亮：被选中的信号整行底色 `--c-link`
- 无障碍：每个格子有 aria-label（如“out，第 3 步，实际 0，你的预测 1，对不上”）；不只靠颜色，必须带 ✓ / ✗
- 数据来源：裁判 JSON 的 `sim.trace`，前端不自行推算任何值

## 7. 文案规范
| 场景 | 用 | 不用 |
|---|---|---|
| 结果不一致 | 对不上、再看看 | 错误、失败 |
| 请求提示 | 再给我一点提示 | 查看答案 |
| 预测提交 | 锁定我的预测 | 提交答案 |
| 空状态（题目列表） | 还没有布置作业，可以先从“组合逻辑”开始练 | 暂无数据 |
| 大模型不可用 | 当前为简化提示，不影响仿真和判定 | 服务异常 |

## 8. 无障碍与质量要求
- 文字与背景对比度 ≥ 4.5:1；所有可点击元素有可见的焦点框
- 所有图标按钮有中文 tooltip 和 aria-label
- 关键页面（做题工作台、我的学情、班级概览）用 Playwright 截图做回归检查
