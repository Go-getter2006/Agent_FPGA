# 页面与交互说明

两种角色、两套界面：
- **学生端**：帮学生学。主线是做题工作台里的 PRIMM 五步：预测 → 运行 → 探究 → 修改 → 创作
- **教师端**：看全班学情、布置作业、做研究分析（分组、导出）

视觉规范见 docs/ui-design.md，静态原型见 docs/ui-prototype.html（做页面时对照它的布局和配色）。各页面展示的指标定义见 docs/learner-model.md，接口见 docs/data-api.md。

## 0. 全局
- 路由：`/login`、`/student/*`、`/teacher/*`；登录后按角色跳转，角色不对的路由一律重定向
- 首次登录的学生先看到知情同意页（第 S1 节），同意前不能进入其他页面
- 所有页面都要有四种状态：加载中（骨架屏）、空状态（带下一步引导）、出错（中文说明 + 重试按钮）、正常
- 界面文案全部中文；时间按北京时间显示
- 学生端以电脑为主：做题工作台最小宽度 1280px，窗口太窄时提示“请在电脑上做题”；“我的学情”和“复习”页要能在手机上看
- 教师端只做电脑端（最小宽度 1280px）

## 学生端

### S1 登录与知情同意（`/login`、`/student/consent`）
- 登录：学号 + 密码。忘记密码提示“请联系任课教师重置”
- 知情同意：说明收集哪些数据、用于什么研究、如何匿名、可随时撤回；按钮“同意并开始”和“暂不参与研究”。不参与研究的学生照常使用全部功能，只是数据不进研究导出
- 记录事件 `consent.accept` 或 `consent.decline`

### S2 学习首页（`/student`）
从上到下：
1. 问候与今日任务：教师布置了作业时显示“本周作业”（截止时间、完成进度条）；没有作业时显示“接下来做”（按题目顺序推荐，入门题在前）；“继续上次”的题
2. 待复习：今天到期的提取练习条数，按钮“开始复习”（进入 S6）
3. 知识点掌握图（缩略版，点击进 S5）
4. 最近一次反馈：上一道题的结果摘要和象限徽章

### S2b 新手入门（`/student/learn`、`/student/learn/:id`）
给完全没学过 Verilog / FPGA 的同学（2026-11 加入）。6 节短课：FPGA 和 Verilog 是什么 → 和 C 语言的不同（硬件同时工作）→ 模块和端口 → 组合逻辑 → 时序逻辑 → 计数器、分频和看波形调试。
每节：讲解（Markdown，代码块有 Verilog 高亮）→ 可以点的电路示意（点输入格子切换 0/1，输出立刻重算；标明是示意动画，不是 iverilog 仿真）→ 小测（答完马上看解析）→ 动手练习（链接到对应的入门题）。
课程列表下面有术语表。学习首页顶部有“第一次学 Verilog 和 FPGA？”的入口。
入门题 4 道（`problems/b1_*`–`b4_*`，排在题目列表最前，带“入门”标记）：与门（预测）→ 二选一选择器（修改）→ 带使能的寄存器（预测）→ 让 LED 闪起来（创作）。

### S3 题目列表（`/student/problems`）
- 左侧筛选：知识点 / 状态（未开始、进行中、已通过、真掌握）。2026-11 去掉了“作业”筛选；教师布置了作业时，列表多一列“截止”
- 切换筛选时保留上一次的列表（稍微变淡），新结果到了再替换，页面不闪（教师端切换分组、学生、题目时同样处理）
- 列表每行：题名、知识点标签、类型（预测题、修改题、创作题）、难度（1–3 个点）、状态徽章、截止时间
- 点击进入做题工作台

### S4 做题工作台（`/student/problems/:id`）——核心页面

#### 布局
```text
┌──────────────────────────────────────────────────────────────────────┐
│ ← 题目  序列检测器（101） [状态机][非阻塞]    ①预测 ②运行 ③探究 ④修改 ⑤创作 │
├────────────────┬───────────────────────────────┬─────────────────────┤
│ 任务卡（当前步骤）│ 代码编辑器（Monaco）              │ 助教面板              │
│ 题目说明（可折叠）│                                │  本题状态（象限徽章）   │
│ 预测结果摘要     ├───────────────────────────────┤  提示阶梯（1→2→3 级） │
│                │ [波形对照] [硬件] [顺序打乱实验]   │  对话                │
│                │ 波形面板 / 硬件面板 / 实验面板     │                     │
└────────────────┴───────────────────────────────┴─────────────────────┘
```
- 左栏 320px、右栏 360px，都可折叠；中间上下分割，默认 55% / 45%，可拖动
- 顶部步骤条显示五步，已完成打勾，当前步骤高亮；不能跳过“预测”直接“运行”（对照组除外，见 docs/learner-model.md 实验分组）

#### 五步的行为
| 步骤 | 学生做什么 | 系统做什么 | 记录的事件 |
|---|---|---|---|
| ① 预测 | 读代码（预测题、修改题用起始代码；创作题用自己写的代码），在波形面板里填 problem.yaml 指定的预测格；回答硬件问题：会综合出几个触发器、有没有锁存器、哪些信号会变成寄存器 | 预测提交后锁定，不能再改 | `predict.submit` |
| ② 运行 | 点“仿真” | 排队 → 编译 → 仿真 → 综合，进度逐项显示；完成后波形面板切到对照模式：预测对的格子打勾，对不上的格子标红并给出“第一个对不上的周期”竖线；硬件面板并排显示“你的预测 / 实际” | `code.submit`、`judge.done` |
| ③ 探究 | 三个小任务：在波形里点出第一个对不上的格子；在编辑器里点出决定这个信号的代码行；用一句话解释原因 | 用裁判结果检查前两项（first_mismatch 和 drivers），答对打勾，答错只说“再看看”，不给答案；解释原文保存 | `investigate.locate_step`、`investigate.locate_line`、`explain.submit` |
| ④ 修改 | 按任务卡的修改目标改代码；**改完先预测变化，再运行** | 同 ②，并对比修改前后的波形 | 同 ①② |
| ⑤ 创作 | 按题目说明从头写设计，并写自己的 testbench（提供 tb 模板） | 判设计；用错误样本给 testbench 打分，显示“你的激励抓住了 3/4 个 bug”，列出没抓住的 bug 的提示（只说类型，不给代码） | `code.submit`、`tb.submit` |

预测题只走 ①②③；修改题走 ①②③④；创作题走 ①（预测自己的代码）②③⑤。第一次运行失败后可以多次重新提交；每次重新提交前都要先填预测格（格数少，不会太烦）。

#### 波形面板（WaveformView，四种模式）
- `predict`：输入信号预先填好；输出信号在要预测的 STEP 显示“?”格。单比特信号点击切换 0/1；总线信号点击后弹出小输入框，支持二进制或十六进制
- `result`：只显示实际仿真波形
- `compare`：每个输出信号显示两行：“期望”（参考答案）和“你的电路”（学生代码的实际结果）。两路信息分开表示：
  - 你的电路与期望不同的格子：浅红底红框；第一个不同的周期画红色竖线，标注“第一个对不上的周期”
  - 预测对不对：在“你的电路”行的预测格右上角显示徽标，预测对为绿色 ✓，预测错为琥珀色 ✗，并在格子下方写“你预测 1”
- `diff`：两条轨迹对比（顺序打乱实验、修改前后），不同的格子高亮
- 联动：点击某个信号的格子 → 编辑器高亮驱动这个信号的代码行（来自 drivers），并滚动到可见位置；鼠标悬停代码行 → 波形里高亮这行赋值的信号
- 例外：在探究步骤里，学生完成“在代码里点出决定这个信号的那一行”之前，不自动高亮驱动行，否则等于直接给出答案
- 键盘：方向键在格子间移动，空格切换 0/1，回车确认总线值

#### 硬件面板
- 三个问题并排：触发器个数（你的预测 / 实际）、锁存器（有 / 无）、哪些信号成了触发器（芯片样式的信号标签，预测错的标出来）
- 下方一句话说明这些数字从哪来：“以上由 Yosys 综合后统计”

#### 顺序打乱实验面板（并行相关知识点的题目才显示）
- 按钮“打乱 always 块的顺序，再仿真一次”
- 结果：顺序无关 → 绿色“你的电路与执行顺序无关，和真实硬件一致”；顺序相关 → diff 模式展示两条轨迹，并给出引导问题“真实电路里这两个块谁先谁后？”
- 讲解卡（可展开）：仿真器是顺序执行的程序，要模拟并行硬件；非阻塞赋值先算好所有右边，再统一更新左边

#### 助教面板
- 顶部：本题状态徽章（四象限之一，学生端用通俗名称，见 docs/learner-model.md）
- 提示阶梯：1 级定位 → 2 级概念 → 3 级类比。每次只能解锁下一级；两次提示之间要求间隔 30 秒，或中间有一次新的提交 / 定位操作（教师可在后台调整）
- 对话：流式输出；输入框上方小字“助教不会直接给你答案”
- 大模型不可用时自动换成规则提示，界面显示“当前为简化提示”

#### S4 第 2 版改动（2026-11，按试用反馈）
- 三栏和中栏、右栏的上下分区都可以拖动分隔条调整大小、点箭头收起（antd Splitter），大小记在浏览器里；左栏题目说明完整显示，内容多时左栏滚动；滚动条一直可见
- 顶栏下面加“下一步”提示条：一句话告诉学生现在该做什么，该点的按钮 / 标签 / 区域闪烁（系统设置了“减少动态效果”时改为静态描边）
- 第一次进入做题页自动弹出分步引导（8 步），顶栏“操作指引”可以再打开
- 页面上的术语（触发器、锁存器、综合、STEP 等）带虚线，鼠标移上去显示通俗解释
- 提示区：1 思路 → 2 定位 → 3 代码提示（带 `____` 的代码框架）→ 4 参考答案（满足条件后解锁，第一次查看前确认）
- 问助教：回复按 Markdown 渲染（代码块高亮、可复制）；有 4 个常用问题可以一键发送；“放大”在大窗口里聊
- 最小窗口宽度从 1280 降到 1024

### S5 我的学情（`/student/report`）
详细指标定义见 docs/learner-model.md。从上到下：
1. 四张概览卡：真掌握的知识点数、会写但没把握的知识点数、波形预测准确率（近 2 周，带升降箭头）、testbench 抓 bug 得分
2. 知识点掌握图：每个知识点一个色块，四级颜色 + 图标 + 文字
3. 预测准确率趋势：波形预测、硬件预测两条线，按周
4. “会写但没把握”清单：题名、哪一步没把握（如“输出时序差了一拍”），按钮“去复习”
5. 最近遇到的误区：通俗说法 + “去练习”链接
6. 徽章：顺序打乱实验通过、testbench 满分等
- **不显示任何排名或与同学的比较**

### S6 复习（`/student/review`）
- 每条复习题 1–3 分钟：只做预测（波形或硬件），提交后立即对照
- 答对 → 进入下一个间隔；答错 → 回到第一个间隔（规则见 docs/learner-model.md 提取练习）
- 页面顶部显示今天剩余条数

## 教师端
布局：左侧菜单 + 顶部班级选择器 + 内容区（卡片网格）。顶部右侧有“匿名显示”开关，默认打开，学生显示为 S01、S02……

### T1 班级概览（`/teacher/classes/:cid`）
1. 五张 KPI 卡：本周活跃人数、作业完成率、全班预测准确率、全班 F 值、平均提示等级（都带与上周对比）
2. 趋势图：近 8 周的预测准确率和 F 值
3. 常见误区 Top 5（横向条形图，点击进 T3）
4. 需要关注的学生（规则见 docs/learner-model.md 预警），每人一行：原因 + “查看详情”
5. 题目速览表：题名、通过率、F 值、盲改率、平均提示等级

### T2 学情热力图（`/teacher/classes/:cid/heatmap`）
- 行 = 学生，列 = 知识点，格子颜色 = 掌握等级（四级）
- 筛选：分组（实验组 / 对照组）、时间范围、作业
- 点格子 → 右侧抽屉显示该生在该知识点上的最近尝试
- 按钮“导出图片”（论文用，默认匿名）

### T3 误区分析（`/teacher/classes/:cid/misconceptions`）
- 标签分布（条形图）；点某个标签 → 说明、涉及学生数、典型代码片段（匿名）、相关题目
- 区分来源：裁判标签（代码层面）和预测误区（理解层面，如“分不清哪些信号会变成触发器”）

### T4 题目分析（`/teacher/classes/:cid/problems/:pid`）
- 指标：通过率、平均提交次数、F 值、盲改率、平均提示等级、平均用时
- PRIMM 漏斗：进入各步骤的人数
- 最常见的“第一个对不上的格子”（STEP × 信号）
- 各提示等级之后下一次提交的通过率，可按提示词版本对比

### T5 学生详情（`/teacher/students/:uid`）
- 时间线：每次尝试一行（象限徽章、标签、预测准确率、用过的提示等级）；点开看代码、波形对照、提示原文、对话记录
- 侧栏：该生各知识点掌握等级、F 值、盲改率、testbench 得分、顺序打乱实验结果
- 对话和解释如已做 ICAP 编码，显示编码结果，并注明“AI 编码，待人工抽检”
- 教师备注（只有教师可见）

### T6 作业与题库（`/teacher/classes/:cid/assignments`）
- 题库来自仓库 `problems/` 目录，界面只读，可预览说明、起始代码、预测点
- 新建作业：选题、选范围（全班 / 某分组）、开始与截止时间

### T7 实验分组与数据导出（`/teacher/classes/:cid/research`）
- 分组：把学生分到实验组 / 对照组（可 CSV 导入），每组的功能开关（预测步骤、智能提示、对话、顺序打乱实验、testbench 打分、复习）
- 导出：事件日志 JSONL、尝试记录 CSV、指标 CSV、数据字典；只含已同意的学生，全部用匿名 ID；导出是后台任务，完成后可下载
- 离线分析：一键对选定时间范围的对话和解释做 ICAP 编码（后台任务，见 docs/llm-deepseek.md），并提供人工抽检界面（随机抽 10%，教师标注后显示一致性 κ）

### T8 班级管理（`/teacher/classes/:cid/roster`）
- 导入名单（CSV：学号、姓名），重置密码，查看知情同意状态
- 这是教师端唯一默认显示真实姓名的页面
