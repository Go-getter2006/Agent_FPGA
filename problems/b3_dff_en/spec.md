# 入门 3：会记忆的寄存器（带使能的 D 触发器）

前两题是**组合逻辑**：输入一变，输出马上跟着变，电路没有记忆。这一题是**时序逻辑**：电路只在**时钟上升沿**那一瞬间更新，其余时间保持不变——它能“记住”一个值。

- `rst` 为 1：在时钟上升沿把 `q` 清成 0（复位优先）
- 否则 `en` 为 1：在时钟上升沿把 `d` 记到 `q` 里
- 否则：`q` 保持原来的值，不管 `d` 怎么变

## 端口
| 信号 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| clk | 输入 | 1 | 时钟，上升沿有效 |
| rst | 输入 | 1 | 同步复位，高有效 |
| en | 输入 | 1 | 使能：为 1 时才记下 d |
| d | 输入 | 1 | 要记下的数据 |
| q | 输出 | 1 | 记住的值 |

## 读懂代码
```verilog
always @(posedge clk) begin
    if (rst)     q <= 1'b0;
    else if (en) q <= d;
end
```
- `always @(posedge clk)`：只在时钟上升沿执行一次里面的内容
- `<=`（非阻塞赋值）：时序逻辑里都用它，表示“在这个时钟沿更新”
- 被这样赋值的 `q` 综合后就是一个**触发器**

## 怎么看波形
每个 STEP 是一个时钟周期：先给输入，时钟上升沿到来，然后采样输出。所以某一步的 `q`，是这一步的上升沿**之后**的值。

## 本题任务（预测题）
代码是对的。重点看 `en = 0` 的那几步：`d` 变了，`q` 会不会跟着变？
