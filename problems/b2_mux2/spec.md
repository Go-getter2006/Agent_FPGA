# 入门 2：二选一选择器

**选择器**像一个拨动开关：选择信号 `sel` 为 0 时，把输入 `a` 接到输出 `y`；为 1 时，把 `b` 接到 `y`。

| sel | y |
|---|---|
| 0 | a |
| 1 | b |

## 端口
| 信号 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| a | 输入 | 1 | sel = 0 时输出它 |
| b | 输入 | 1 | sel = 1 时输出它 |
| sel | 输入 | 1 | 选择信号 |
| y | 输出 | 1 | 选出来的值 |

## 会用到的写法
条件运算符 `条件 ? 值1 : 值2`：条件为 1 取值1，为 0 取值2。和 C 语言写法一样，但在硬件里它是一个**一直在工作**的开关，不是“执行一次”的语句。

## 本题任务（修改题）
起始代码里 `y` 永远等于 `a`。先预测它的输出并运行，看看哪里不对；再按修改目标改代码。
